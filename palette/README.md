# palette - terminal color palette viewer

palette prints 256-color and truecolor terminal palettes along with escape code references.

## Usage

```bash
palette [OPTIONS]
```

## Options

- --256: show only 256-color grid
- --truecolor: show only truecolor gradients
- --codes: include escape code references
- -h, --help: show help

## Examples

```bash
palette
palette --256 --codes
palette --truecolor
```
